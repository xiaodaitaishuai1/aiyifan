# 首页横幅与两列卡片设计

## 目标

将首页内容区改为参考 `com.cqcsy.ifvod` 的信息层级：当前分类先展示一张横幅，再以每行两张的形式展示剩余影片。热门页不在本次改动范围内。

## 数据与交互

- `CatalogRepository.getHomeVideos(categoryId)` 仍是唯一的数据来源，不增加接口或模型字段。
- 当前分类影片列表的第一项作为横幅数据源；其余项作为两列卡片数据源。
- 横幅和卡片均沿用现有跳转：点击后打开 `VideoPlayerActivity` 并传入影片 `mediaKey`。
- 切换分类、下拉刷新完成后，使用最新列表重新划分横幅与卡片。
- 空列表时不显示横幅或卡片；加载异常仍保留现有 Toast 与停止刷新逻辑。

## UI 结构

- 保留首页顶部搜索入口、分类横向标签及 `SwipeRefreshLayout`。
- 将首页 RecyclerView 改为两列 `GridLayoutManager`。
- 新建首页专用 Adapter，使用两种 ViewType：
  - 横幅占满两列，封面比例为 16:7，标题在底部渐变遮罩上展示。
  - 常规卡片每项占一列，封面比例为 16:9，标题位于封面下方并限制为两行。
- 新建横幅与两列卡片 XML，复用现有颜色、圆角和 Glide 图片加载方式；不修改热门页所用的 `VideoListAdapter` 或其纵向卡片布局。

## 状态与边界

- 只有一部影片时，仅展示横幅。
- 封面 URL 为空时清除 Glide 请求，保留 XML 占位背景。
- 横幅和卡片的点击均不依赖展示位置，以同一 `VideoSummary` 回调处理。

## 验证

- 先为首页数据分流和 Adapter ViewType 写失败测试：空列表、单项列表、多项列表。
- 测试首页布局配置两列网格，并验证横幅布局的全宽比例与卡片布局的 16:9 比例。
- 运行相关单元测试、`assembleDebug` 和 `lint`。
- 通过连接的 Pixel 6 安装 Debug APK，确认横幅、两列卡片、分类切换和播放跳转的实际展示。
