# 播放器手势与系统悬浮窗控制设计

## 目标

为视频播放器增加左右区域的音量、系统亮度手势，以及长按后横向快进快退；为系统悬浮窗增加剧集切换和双击回到应用的能力，同时保持播放进度和当前剧集状态一致。

## 范围

- 播放器画面左半区上下滑直接调整手机系统亮度。
- 播放器画面右半区上下滑调整媒体音量。
- 在播放器画面长按连续满两秒后，继续左右滑动预览快进或快退；松手时提交目标进度。
- 系统悬浮窗提供上一集、播放/暂停、下一集和关闭控制；第一集禁用上一集，最后一集禁用下一集。
- 系统悬浮窗视频区域的双击关闭悬浮窗并恢复既有播放页到前台；播放页恢复时显示当前剧集并保留服务记录的进度。

不改变 Android 画中画模式或应用内迷你播放器的控制项。

## 方案选择

采用共享播放会话方案。应用内 `VideoPlayerActivity` 和 `FloatingPlayerService` 通过一个共享的播放会话协调器读取和修改当前详情、当前剧集与队列位置。协调器是剧集前后导航的唯一入口，负责计算边界；各界面仅负责发起操作和更新视图。

相比仅向 Activity 派发事件，这个方案在 Activity 进入后台时仍可由悬浮窗切换剧集；相比由悬浮窗独立维护播放数据，它避免回到应用后标题、选集和播放进度不同步。

## 播放器手势

播放器画面使用一个可测试的手势决策器，将一次触摸序列归类为亮度、音量、长按横向快进快退或普通点击。普通点击继续交给现有 `PlayerView` 控制层处理。

- 手势起点位于左半区时，垂直滑动把起始系统亮度按屏幕高度的比例映射到 `0..255`。首次检测到无“修改系统设置”权限时，跳转至该应用的系统授权页，不修改亮度。
- 手势起点位于右半区时，垂直滑动把起始媒体音量按屏幕高度的比例映射到 `0..最大媒体音量`。
- 长按只有在触点两秒内未移动超过触摸阈值时才能激活。激活后，水平位移相对播放器宽度映射为目标进度偏移；界面显示快退/快进方向和预览时间，松手才调用 seek。目标值始终限制在 `0..duration`；时长未知或非正时不执行 seek。
- 亮度、音量和 seek 预览均由短暂的播放器内浮层提供文字反馈，互不叠加。

## 系统悬浮窗

现有 `FloatingPlayerService` 的控制层扩展为：左侧上一集、中部播放/暂停、右侧下一集、右上关闭。控制显示与自动隐藏沿用现有规则；剧集切换后重新显示控制层并刷新三枚按钮状态。

悬浮窗根视图使用双击检测：单击维持现有显示或隐藏控制层的行为，拖动和缩放不触发点击，双击视频区域会保存当前进度、移除悬浮窗，并以已有任务恢复 `VideoPlayerActivity`。如果 Activity 已被系统回收，则使用共享播放会话中的媒体标识新建页面，并恢复当前剧集及进度。

## 错误和回退

- 无系统亮度写入权限：仅打开系统授权页，不改变亮度。
- 找不到相邻剧集：对应悬浮窗按钮禁用，点击不产生播放请求。
- 相邻剧集无法解析播放地址：保持当前剧集与当前播放，不更新会话状态，并给出短提示。
- 双击恢复失败：悬浮窗保持显示，避免无播放界面。

## 测试与验收

新增 JUnit 4 覆盖：手势类型选择、亮度/音量范围钳制、长按两秒门槛、seek 目标钳制、首尾剧集边界、单击与双击的悬浮窗动作选择，以及切集后共享会话状态更新。

验收时在 Android 设备上确认：授予系统设置权限后亮度真的修改系统值；右侧手势调节媒体音量；两秒长按再横滑只在松手后跳转进度；悬浮窗能正确切集、双击回到相同剧集与进度。运行相关单测、`./gradlew.bat test` 与 `./gradlew.bat lint`。
