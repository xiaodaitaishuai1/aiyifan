# 首页刷新动效与图片加载设计

## 目标

让首页下拉刷新和上拉分页都有清晰、轻量的主题化加载反馈，并缩短封面从占位到可见的感知等待时间。

## 交互

- 下拉刷新继续使用 `SwipeRefreshLayout`；旋转环使用当前主题的 `accent` 色，刷新结束后由现有状态统一收起。
- 上拉到底开始分页时，RecyclerView 显示一个占满两列的底部加载项，内含无文字的主题色圆形旋转指示器；网络返回或失败后移除该项。
- 当前分类已无后续页时不显示底部加载项，保留现有“没有更多了”提示。
- 刷新与上拉期间不重复发起同页请求。

## 图片

- 首页横幅和卡片封面统一使用 `poster_placeholder` 作为立即可见的占位与错误状态，颜色由 `values/` 与 `values-night/` 自动切换。
- 首页首屏请求使用 Glide 的高优先级、磁盘缓存和 160ms 淡入；卡片根据目标尺寸解码，减少首屏图片解码对滚动的影响。
- 代理感知 OkHttp 客户端保留并复用现有连接池；不变更图片 URL、代理策略或播放页。

## 验证

- 单元测试验证首页源码接入刷新颜色、底部加载状态和图片请求选项。
- 真机检查浅色与深色主题下的顶部和底部指示器颜色、下拉刷新、上拉追加与封面占位/淡入。
