# 片头片尾自动跳过设计

## 目标

复刻参考 APK 的片头片尾自动跳过：默认开启，播放新剧集时从片头结束位置开始；到达片尾开始位置时自动切换下一集。

## 数据与状态

- `Episode` 新增可选的 `opSecond` 和 `epSecond`，单位为秒。
- 远端详情和播放地址响应都解析这两个字段；播放地址响应的值优先，以便各清晰度保留正确时间点。
- `AutoSkipPreferenceStore` 使用 `SharedPreferences` 保存 `auto_skip_intro_outro`，默认值为 `true`。

## 播放规则

- 续播位置大于零时优先续播，绝不因片头跳过覆盖用户进度。
- 续播位置为零、开关开启且 `opSecond` 大于零时，以 `opSecond * 1000` 作为初始播放位置。
- 每次收到播放器进度时，开关开启、`epSecond` 有效、当前进度达到该位置、且存在后续剧集时，自动加载下一集。
- 为避免进度回调重复触发，当前剧集只允许自动切换一次；用户手动选择剧集或成功加载下一集时重置该状态。
- 缺少时间点、无后续剧集、播放器未准备完成或自动跳过关闭时，不改变当前播放。

## 界面

- 在播放详情页操作区加入“自动跳过片头片尾”开关。
- 开关使用现有应用的文本按钮和主题风格，状态改变立即持久化。
- 自动跳过片头或片尾切集时显示短 Toast 提示。

## 验证

- 单测覆盖初始位置优先级、无效片头时间、片尾触发、无下一集和重复触发。
- 远端解析测试覆盖详情和播放响应中的片头片尾字段。
- 执行相关本地单测和 `lint`。
