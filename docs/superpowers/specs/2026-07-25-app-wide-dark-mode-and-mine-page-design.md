# 全应用暗黑模式与“我的”页优化设计

日期：2026-07-25

## 目标

为爱壹帆 Android 应用提供稳定的系统跟随暗黑模式，并改善“我的”页的视觉层级和操作可发现性。主题改造覆盖首页、热门、搜索、登录、列表、代理设置、视频详情和播放器；播放器继续保留黑色沉浸式播放体验。

## 已确认的产品决策

- 主题策略采用方案 A：由应用跟随系统的浅色或深色外观自动切换。
- 主题覆盖全应用，而不是只覆盖“我的”页。
- “我的”页保留登录、观看记录、我的收藏和网络代理的既有跳转行为。
- 不新增手动浅色／深色设置，也不改变应用的数据、登录或代理业务逻辑。

## 当前问题

1. `AppTheme` 已继承 `DayNight`，但页面颜色和多个 Drawable 均固定为浅色，切换到系统深色外观时无法完成视觉适配。
2. 页面背景、卡片、输入框、描边和次级文字没有统一的夜间资源；底部导航与边到边系统栏也没有按主题校准。
3. “我的”页缺少页面标题，访客头像显示与身份无关的“壹”，登录提示与动作的层级较弱。
4. 观看记录、我的收藏、网络代理使用外观相同的普通按钮，缺少图标、分组和进入箭头，内容扫描效率低。

## 技术设计

### 主题资源

- 继续使用 `Theme.MaterialComponents.DayNight.NoActionBar`，由系统的 `uiMode` 驱动日间与夜间外观。
- 保留 `values/colors.xml` 作为浅色语义色板，并新建 `values-night/colors.xml`，用同名资源覆盖：页面背景、卡片表面、主／次文字、输入框、描边及底部导航所需颜色。
- 将现有会暴露在常规页面中的硬编码浅色 Drawable 颜色替换为语义色资源；透明黑色播放控件和播放器背景不参与常规页面反色。
- 为主题增加状态栏与导航栏图标明暗属性，边到边布局的图标颜色随系统主题正确反转。

### “我的”页

- 添加“我的”标题，作为页面的首要视觉锚点。
- 将用户区域设为圆角资料卡：圆形访客头像、用户名称、同步提示和登录按钮。
- 用两个圆角分组替代孤立的全宽按钮：
  - 内容与数据：观看记录、我的收藏。
  - 应用设置：网络代理。
- 每个入口使用与现有 Material 视觉风格一致的圆角图标、明确标题和右侧进入箭头；使用资源化 content description，保证可访问性。
- 继续由 `MineFragment` 处理既有跳转，不引入新的页面或业务状态。

### 应用范围

- 首页、热门、搜索、登录、通用列表、代理设置、视频详情以及“我的”页使用同一套语义色资源。
- `MainActivity` 的底部导航、每个 Activity 的页面背景和可编辑控件在深色主题中保持足够对比度。
- 视频播放器的播放画布和悬浮控件维持其现有深色沉浸式策略，仅处理其非沉浸式文字与表面的主题兼容性。

## 错误处理与兼容性

- 不存储用户主题偏好，因此不存在偏好文件损坏或恢复失败路径；应用始终以当前系统 `uiMode` 为唯一来源。
- Android 24+ 均由 AppCompat `DayNight` 和资源限定目录支持；系统切换主题时，Activity 重建后自动重新取用对应资源。
- 图标使用本地 Material 风格矢量资源，不依赖网络加载。

## 验证

1. 更新“我的”页布局测试，验证资料卡、分组入口与主题相关控件存在且结构正确。
2. 通过 Android 资源编译验证浅色与夜间资源具有完整、同名的语义颜色定义。
3. 运行 `./gradlew.bat test`、`./gradlew.bat lint` 和 `./gradlew.bat assembleDebug`。
4. 在 Android 设备或模拟器中分别以浅色和深色系统外观检查首页、热门、“我的”、搜索、登录、列表、代理设置和播放页，确认文字、输入框、底部导航与系统栏可读。
